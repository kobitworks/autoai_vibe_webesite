# AutoAI Vibe Coding Lab

AutoAI の子プロジェクトとして、バイブコーディングによる小規模Webサイト／ミニWebアプリを継続的に作るリポジトリです。

## Project hierarchy
- Parent: AutoAI
- Child: バイブコーディングWeb開発
- Grandchildren: 個別のWebサイト／ミニWebアプリ

## Basic flow
1. 最小限の要望を整理
2. 操作可能なPoCを作成
3. GitHub Pagesで確認
4. 実際に触りながら仕様を調整
5. 必要なものだけ本番化
